Connecting GitHub

Create a fine-grained personal access token at GitHub → Settings → Developer settings → Fine-grained tokens. Choose the repositories you want, and set Issues, Pull requests and Metadata to Read-only. Paste the token into RepoGlance. The app never needs write access.

Choosing what a widget shows

Touch and hold the widget on your Home Screen, tap Edit Widget, then pick the repositories and their order. Each widget can show a different set. Widgets can't scroll, so longer lists show a page button (for example 1/3 ›).

Counts look out of date

The widget updates when you open the app, and in the background when iOS allows. Pull down on the Overview to refresh now. If GitHub's rate limit is reached, the app shows when you can try again.

A repository shows “Unavailable”

GitHub couldn't find it: it may have been deleted or renamed, or your token may not include it. Edit the token's repository access on GitHub.

Restoring your purchase

Settings → Restore Purchase, signed in with the same Apple Account.
